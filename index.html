Tanya yang sering masuk

Pertanyaan asli yang datang lewat Telegram dan GitHub, dijawab singkat.

Apa itu 9RouterX dan untuk siapa?

Gateway AI lokal berbasis Go: satu titik masuk OpenAI-compatible untuk semua provider, dengan dashboard, cost limit per key, dan failover. Cocok untuk developer yang sudah bayar banyak API key dan ingin satu dashboard untuk mengaturnya. Repo: github.com/yanstd888/9routerx.

Bagaimana cara mendapatkan subdomain .ai.id gratis?

Buka aiclub.ai.id, pilih subdomain yang tersedia, daftar gratis, lalu arahkan DNS-nya ke hosting kamu (Cloudflare, Vercel, GitHub Pages, semuanya bisa). Panduan lengkapnya ada di repo free-subdomain-aiclub-ai-id.

Untuk siapa humanizer-lint dibuat?

Untuk siapa pun yang tulisannya sering dikirim lewat AI dan ingin memastikan hasilnya tidak terdengar seperti robot. Linter berjalan lokal, tanpa upload, 8 bahasa, dan bisa dipasang sebagai skill AI agent lewat npm atau skills.sh.

Apakah EA MT5-nya pakai martingale?

Tidak. Institutional SMC Scalper MT5 memakai risiko tetap per posisi, tanpa martingale dan tanpa grid. Backtest real-tick 6,5 tahun tersedia di repo agar kamu bisa cek sendiri angkanya.
